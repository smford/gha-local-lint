# CLI Commands Reference

`gha-local-lint` provides a suite of specialized commands for static linting, execution simulation, matrix inspection, DAG visualization, and cost estimation.

---

## `check` — Static Linting & Auto-Remediation

Performs static validation of workflow files against the complete rule catalogue.

```bash
# Check all workflows in .github/workflows/
gha-local-lint check

# Check specific workflow files
gha-local-lint check .github/workflows/ci.yml .github/workflows/release.yml

# Automatically remediate issues in place
gha-local-lint check --fix .github/workflows/*.yml

# Enforce strict 40-character SHA pinning on 3rd-party actions
gha-local-lint check --require-sha-pin .github/workflows/*.yml

# Output SARIF format for GitHub Code Scanning integration
gha-local-lint check --format sarif .github/workflows/*.yml > results.sarif

# Output machine-readable JSON format
gha-local-lint check --format json .github/workflows/*.yml
```

---

## `simulate` — Offline Workflow Execution Engine

Simulates workflow triggers, step execution paths, and status conditions without spinning up cloud runners.

```bash
# Simulate default push to main
gha-local-lint simulate .github/workflows/ci.yml

# Simulate pull_request event against a specific branch ref
gha-local-lint simulate .github/workflows/ci.yml \
  --event pull_request \
  --ref refs/pull/42/merge \
  --actor octocat

# Simulate with changed path detection (respects on.pull_request.paths)
gha-local-lint simulate .github/workflows/ci.yml \
  --event pull_request \
  --detect-changes

# Simulate with step failure propagation
gha-local-lint simulate .github/workflows/ci.yml --fail-job build
```

---

## `matrix` — Strategy Matrix Expander

Evaluates and displays all combinations generated by a job's `strategy.matrix` configuration, accurately computing `include` and `exclude` directives.

```bash
# Display matrix combinations as a formatted table
gha-local-lint matrix .github/workflows/ci.yml

# Output matrix variations as JSON
gha-local-lint matrix .github/workflows/ci.yml --format json
```

---

## `graph` — Workflow DAG Dependency Visualizer

Generates Mermaid or Graphviz DOT graphs representing job dependency trees (`needs:` relationships).

```bash
# Output Mermaid diagram (suitable for GitHub markdown or PR comments)
gha-local-lint graph .github/workflows/ci.yml --format mermaid

# Output Graphviz DOT graph
gha-local-lint graph .github/workflows/ci.yml --format dot
```

---

## `repl` — Interactive Expression Evaluator

Provides an interactive REPL shell for experimenting with GitHub Actions expressions, contexts, and builtin functions.

```bash
gha-local-lint repl
```

**Example REPL Session:**
```text
gha-expr> contains('Hello World', 'World')
true
gha-expr> startsWith('refs/heads/main', 'refs/heads/')
true
gha-expr> format('Hello, {0}!', 'Alice')
Hello, Alice!
gha-expr> fromJSON('{"env": "prod"}').env == 'prod'
true
gha-expr> exit
```

---

## `cost` — Runner Compute & Cost Estimator

Calculates estimated GitHub runner minutes and financial costs per run and monthly based on timeout configurations and matrix expansion dimensions.

```bash
gha-local-lint cost .github/workflows/*.yml
```

---

## `report` — HTML Audit Report Generator

Generates a standalone, styled HTML report summarizing workflow dependencies, security posture, runner consumption, and lint findings.

```bash
gha-local-lint report .github/workflows/*.yml --output report.html
```

---

## `version` — Build Metadata

Displays binary version, commit hash, build date, and license info.

```bash
# Plain text summary
gha-local-lint version

# Machine-readable JSON output
gha-local-lint version --format json
```
