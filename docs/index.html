gha-local-lint

Offline GitHub Actions Expression & Matrix Simulator. Catch broken conditions, script injections, and DAG cycles before git push.

View on GitHub Download Release

Quick Install

# Install with Go (Zero-CGO)
go install github.com/smford/gha-local-lint/cmd/gha-local-lint@latest

# Or run via Homebrew
brew tap smford/homebrew-tap
brew install gha-local-lint

Static Linting & Security Verification

Checks workflow DAG circular dependencies, broken output references, unpinned actions, and script injections with exact line numbers:

# Lint all workflows in .github/workflows/
gha-local-lint check

# Automatically remediate script injections and pin actions
gha-local-lint check --fix

# Export SARIF for GitHub Code Scanning
gha-local-lint check --format sarif > results.sarif

Dry-Run Workflow Simulation

Simulates push and pull request events against mock contexts without burning runner minutes:

# Simulate push to main
gha-local-lint simulate .github/workflows/ci.yml --event push --ref refs/heads/main

# Simulate pull request with changed paths
gha-local-lint simulate .github/workflows/ci.yml --event pull_request --detect-changes

# Expand strategy matrix combinations
gha-local-lint matrix .github/workflows/ci.yml
